How to Use

Simply add the appropriate class to any HTML element:

<!-- Background gradients -->
<div class="blue-gradient-1">Content here</div>

<!-- Text gradients -->
<h1 class="blue-gradient-text-1">Gradient Text</h1>

<!-- Buttons -->
<button class="btn-blue-gradient-1">Gradient Button</button>

<!-- Cards -->
<div class="card-blue-gradient-1">Card content</div>

<!-- Hero sections -->
<section class="hero-bg-blue-1">Hero content</section>

You can also use the CSS variables directly in your own styles:

/* CSS variables available */
--blue-gradient-1: linear-gradient(135deg, #0061ff, #60efff);
--blue-gradient-2: linear-gradient(135deg, #009ffd, #2a2a72);
--blue-gradient-3: linear-gradient(135deg, #4facfe, #00f2fe);
--blue-gradient-4: linear-gradient(135deg, #00c6ff, #0072ff);
--blue-gradient-5: linear-gradient(135deg, #667eea, #764ba2);
